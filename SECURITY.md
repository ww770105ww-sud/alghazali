# Security Policy

Responsible disclosure policy for the Alghazali project.

If you discover a security vulnerability, please do the following:
1. Do not create a public issue.
2. Email security@alghazali.example.com (replace with the actual owner contact) with details.
3. Provide steps to reproduce, affected versions, and suggested mitigation.

We will acknowledge receipt within 48 hours and coordinate disclosure and a fix.

### Recommended public disclosure
After a fix is available, we will coordinate a public disclosure and credit.
