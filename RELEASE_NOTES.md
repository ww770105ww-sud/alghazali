# Release Notes

## Version 1.0.0 – First Stable Release

### Overview
This is the first stable release of the Alghazali travel and tourism management system. The release provides a solid foundation for managing travel services, customer operations, financial processes, and administrative workflows in a unified platform.

### Key Features
- Admin dashboard for operational monitoring.
- Service management for travel-related operations.
- Invoice, payment, and financial workflow support.
- Structured accounting and transaction handling modules.
- Professional documentation and release packaging for production readiness.

### Improvements and Fixes
- Added formal project documentation and release assets.
- Added proprietary licensing and ownership notices.
- Prepared the repository for a professional GitHub release process.

### Requirements
- PHP 8.0 or newer
- MySQL 8.0 or newer
- Web server: Apache or Nginx
- PDO MySQL extension enabled
- Write permissions for the sessions and uploads directories

### Installation
1. Clone the repository to your server.
2. Create a MySQL database and import the SQL structure from the database scripts in the repository.
3. Configure your database credentials in the environment settings used by the application.
4. Upload the project files to your web server.
5. Set appropriate permissions for the sessions and uploads folders.
6. Open the admin panel in your browser and sign in.

### Release Notes
This release is intended for initial stable deployment and professional version control tracking. Future updates will be published through new tags and GitHub releases.
